Engineering Rules & Agent Guardrails

Mandatory development standards for humans and AI agents (Antigravity, Claude CLI) working on the CPUwiser codebase.

The 7 Absolute Rules

Rule 1: Private Network Isolation

Never expose worker RPC or distributed-llama ports to the open internet. Bind exclusively to loopback, internal Docker networks, or WireGuard.

Rule 2: Never Commit Secrets

Never commit SSH keys, WireGuard keys, API keys, Oracle tenancy OCIDs, or public IP addresses. Maintain sample files in profiles/*.example.yaml.

Rule 3: Enforce Oracle Always Free

Never create paid shapes. Always confirm the Always Free label in OCI before instantiating resources.

Rule 4: Zero Invented Numbers

Every performance number must stem from a physical run in results/ or carry confidence tags: [V], [S], [E], or [U].

Rule 5: Verify CLI Tool Flags

Engine options change across versions. Run <tool> --help on the pinned commit rather than guessing command options.

Rule 6: Strict Version Pinning

Every benchmark result must record engine git SHA, model file SHA-256, OS kernel version, and CPU microarchitecture.
