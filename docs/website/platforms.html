Multi-Cloud Design

Pluggable Providers & Frontend Integration

How CPUwiser abstracts cloud infrastructure behind generic node providers, overlays multi-cloud networking via WireGuard, and integrates frontend web clients.

The Provider Abstraction Rule

Decoupled Vendor Interfaces: The core experiment runner never talks directly to cloud vendor APIs. Instead, it interacts strictly with an abstract NodeAccess interface (SSH or Docker exec). This allows seamless swapping of nodes between Local Docker, Oracle, AWS, or local bare metal!

Where Does Vercel Fit?

Vercel is an exceptional serverless platform for hosting frontend user interfaces, but its serverless functions have a 10–60 second maximum execution timeout and zero persistent RAM for holding gigabytes of model weights.

Vercel: What Works

Frontend Web Dashboard

Host Next.js or static documentation/chat pages on Vercel. The web client queries the Master node directly or via a lightweight streaming proxy.

Vercel: What Does Not Work

Running Engine Workers

Serverless lambdas terminate after brief requests and cannot keep neural network weights in RAM or bind persistent TCP/RPC listening sockets.

Multi-Cloud Overlay Network (WireGuard)

When combining a laptop with an Oracle VM or an AWS guest instance, nodes reside in separate private subnets. CPUwiser links them using a lightweight WireGuard VPN mesh, giving every node an internal 10.42.0.x IP address with end-to-end encryption.
