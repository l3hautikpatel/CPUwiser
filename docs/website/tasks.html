Development Roadmap

Milestones & Actionable Task Board

Sequential execution roadmap organized across milestones M0 through M7. Each task corresponds to a focused pair-programming session with strict acceptance criteria.

Milestone Summary

M0: Bootstrap

Repository layout, Python 3.12 project setup, uv package manager, ruff, pytest, CI actions.

M1: Host Baseline

Local pinned llama.cpp build, single-machine tok/s control measurement (A1 experiment).

M2: Docker Lab

Multi-container Docker Compose simulation, Linux traffic control (tc netem) latency sweeps.

M3: Profile & Planner

Pydantic profile parser and constraint-solving planner producing deterministic execution plans.
