How the Nodes Talk & How You Use the LLM

Detailed journey of a single prompt from your client through the master coordinator down to the worker nodes, network boundaries, and daily operations.

The Golden Rule: You only ever talk to the Master (Coordinator) node over an OpenAI-compatible HTTP interface (/v1/chat/completions). Workers are never contacted directly by your client or web application.

The Prompt Execution Pipeline

Single Prompt Journey Through Distributed CPU Nodes Interactive Architecture

Step-by-Step Prompt Journey

Step Who Executes Operation Network Traffic
1. Request In Client $\rightarrow$ Master POST /v1/chat/completions with user prompt text. Tiny JSON payload over HTTP.
2. Tokenize Master only Transforms text to token IDs; computes embeddings for first chunk of layers. Local CPU only (0 network).
3. Prefill / Layers Master & Workers Tensors/activations pass along the layer split (Master $\rightarrow$ Worker 1 $\rightarrow$ Worker 2). RPC over private network/overlay (high bandwidth).
4. Sample Token Master only Master gathers final logits tensor and runs sampling (temperature, top-p, greedy). Worker sends single activation vector back to Master.
5. Stream Back Master $\rightarrow$ Client Token text decoded and sent back via SSE (Server-Sent Events) chunk to user. Immediate user-facing response chunk.

How You Use the LLM Day-to-Day

Option 1: Web Chat UI

Browser Chat

Open the web chat demo in your browser. Shows real-time token generation, streaming speed (tok/s), and active cluster topology.

Option 2: Terminal cURL

Standard OpenAI cURL

curl http://127.0.0.1:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"messages": [{"role": "user", "content": "Hello!"}], "stream": true}'
Option 3: External Projects

SDK / LangChain / LiteLLM

Point any application using openai.OpenAI(base_url="http://master:8080/v1", api_key="dummy") straight to the master node.
