How to Set Up Machines (Oracle Cloud & AWS)

Exact console selections, shape parameters, budget guardrails, and automated bootstrap commands for setting up cluster nodes.

The Zero-Dollar Cloud Mandate: Only use one single Oracle account with the Always Free tag. Never provision paid shapes or exceed 4 OCPU / 24 GB total. If any prompt or console screen displays an hourly cost, cancel immediately!

1. Oracle Cloud Setup: The 2-Node Cluster (S1 Configuration)

This layout gives us a genuine distributed testbed without exceeding the free limits:

Node Name Shape & CPU Architecture OCPU Allocation RAM Boot Volume Role
node-1 VM.Standard.A1.Flex (Ampere Arm) 1 OCPU 6 GB 50 GB (Ubuntu 24.04 aarch64) Master / Coordinator
node-2 VM.Standard.A1.Flex (Ampere Arm) 1 OCPU 6 GB 50 GB (Ubuntu 24.04 aarch64) Worker

Console Step-by-Step Checklist

  1. Log into Oracle Cloud Console. Confirm the Always Free Eligible banner is visible.
  2. Virtual Cloud Network (VCN): Use "Start VCN Wizard" $\rightarrow$ "Create VCN with Internet Connectivity". Name it cpuwiser-vcn.
  3. Security Lists: Ensure internal subnet allows ingress on port 22 (SSH) and port 50052 (RPC) between 10.0.0.0/16. Do not open 50052 to 0.0.0.0/0!
  4. Create Compute Instances:
    • Image: Canonical Ubuntu 24.04 Minimal (aarch64).
    • Shape: Ampere $\rightarrow$ VM.Standard.A1.Flex $\rightarrow$ 1 OCPU, 6 GB RAM.
    • SSH Key: Paste your dev laptop public key (~/.ssh/id_ed25519.pub).
    • Boot Volume: Leave at default (50 GB). Total for 2 nodes = 100 GB (well under 200 GB limit).

2. AWS Guest Node (S3 Option — Optional 3rd Node)

Select Ubuntu 24.04 ARM64 AMI, t4g.small (2 vCPU, 2 GB RAM). Join to Oracle master via WireGuard overlay mesh. Set a strict AWS Billing Alert for $1.00!

3. Universal Node Bootstrap Script (Task T-042)

Once your nodes are reachable via SSH, run the unified bootstrap script to install toolchains and build the pinned engine binaries: 

#!/usr/bin/env bash
# cpuwiser-bootstrap.sh — Run on every fresh Ubuntu node
set -euo pipefail

sudo apt-get update && sudo apt-get install -y \
  build-essential cmake git curl python3-pip wireguard net-tools

# Clone and compile pinned llama.cpp version
if [ ! -d "/opt/llama.cpp" ]; then
  sudo git clone https://github.com/ggerganov/llama.cpp /opt/llama.cpp
  cd /opt/llama.cpp
  sudo git checkout b3800  # Pinned commit hash
  sudo cmake -B build -DGGML_RPC=ON
  sudo cmake --build build --config Release -j$(nproc)
fi

echo "Node bootstrap complete. Pinned llama.cpp with RPC ready."
