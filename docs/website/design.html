Architecture Specification

Components, Schemas & Interfaces

Detailed breakdown of CPUwiser's core Python modules, YAML profile schemas, constraint solver planner logic, and engine adapter lifecycle.

1. Design Principles

  • Profile in, plan out, results recorded: Every run is driven by data (profile YAML, plan spec, experiment spec) and produces an immutable, self-contained record.
  • One engine adapter per engine: All runtime backends conform to a unified interface so experiments run agnostic of whether llama.cpp RPC or distributed-llama is executing.
  • Pure core, thin shell: Profile loading, planning, and command compilation are pure functions, completely testable without Docker or cloud VMs.
  • Reproducible by construction: Model hash (SHA-256), git commit of the engine, CPU microarchitecture, and kernel are stamped into every result.

2. Core Modules Breakdown

Module Responsibility Dependencies
cpuwiser.profile Loads, validates, and normalizes YAML cluster descriptions into immutable dataclasses. None (stdlib + pydantic/yaml)
cpuwiser.planner Solves layer-split allocations, thread binding, context sizes, and warns on memory over-commit. profile, model metadata
cpuwiser.engines Adapters for starting, supervising, and parsing stdout from coordinator & worker processes. profile, planner
cpuwiser.runner Executes experiment sweeps, configures tc netem, captures performance telemetry. engines, infra
cpuwiser.infra Local Docker Compose lifecycle, SSH node bridges, network delay proxies, host resource samplers. None
cpuwiser.report Aggregates run logs, fits latency slopes (RTT vs tok/s), outputs markdown tables and charts. results/ data

3. Cluster Profile Schema (YAML)

A cluster profile declaratively represents all nodes participating in an inference cluster:

cluster:
  name: "oracle-free-tier"
  description: "2x Arm A1 (2 OCPU each) + 2x AMD Micro"
  nodes:
    - name: "arm-node-01"
      role: "coordinator"
      arch: "aarch64"
      cpu_cores: 2
      ram_mb: 12288
      ip: "10.0.0.2"
      cost_per_hr: 0.00
    - name: "arm-node-02"
      role: "worker"
      arch: "aarch64"
      cpu_cores: 2
      ram_mb: 12288
      ip: "10.0.0.3"
      cost_per_hr: 0.00
network:
  type: "simulated-lan"
  baseline_rtt_ms: 0.2
  emulated_delay_ms: 5.0
  bandwidth_mbps: 1000
